## 用途与角色设定

库洛是 Windows 桌面聊天软件中的陪伴角色，在聊天窗口右侧展示。软件使用 Electron + React，后续计划接入支持相应模型版本的 Cubism Web 运行时。

角色气质：亲切、温柔、活泼，像一起整理思路和解决问题的小搭档。保留现有 Q 版比例，面部在较小尺寸下仍需清楚。

固定外观：

- 珊瑚粉长卷发，发尾带少量柔和淡紫色阴影。
- 粉珊瑚色眼睛，柔和肤色和淡腮红。
- 两侧龙虾钳造型发饰，白色小花和蝴蝶结装饰。
- 头顶两根触须形发束，作为角色识别点。
- 奶油白针织开衫、浅色水手领、珊瑚色胸前蝴蝶结和小花。
- 下摆衔接珊瑚粉格纹裙，具体制作范围按半身构图确认。

配色以参考图为准，画师可以为了线条可读性适当整理细节。参考图中的小装饰和针织纹理不要求机械复制。

## 第一版立绘范围

制作正面半身角色，头部和肩膀保持水平，两眼睁开，默认闭嘴微笑。手臂放松、与身体略微分开，便于后续处理。应用显示时裁切至腰部附近；模型具体下边界由画师和绑定师共同确认，保证身体摆动时不露出缺口。

新参考图为了说明服装，画到了裙摆；这不代表第一版需要全身绑定。主视图和右侧表情小图是外观说明，不是可以直接导入 Cubism 的分层素材。

运行素材需要透明背景。头发、触须和饰品需要保留摆动余量。主立绘不带电脑、坐垫和背景装饰，避免遮住躯干。

建议原画长边约 3000–4000 像素，最终画布及纹理尺寸由制作方根据展示尺寸和性能确定。半身展示预计宽约 250–350 个界面像素，眼睛、嘴巴与发饰应在该尺寸下清晰。

## 分层与绑定要求

请画师与绑定师先对齐分层规范。下列为功能要求，具体图层结构可由制作方调整：

- 面部底色、脸部轮廓及所需阴影分开；转头时暴露的区域需要补画。
- 左右眉分别分层；左右眼的眼白、虹膜、瞳孔、主要高光和上下眼皮按绑定需求拆分。
- 嘴部按开合需求拆分嘴线、口腔及必要内部部件。
- 刘海、侧发、后发、触须分组，发束按物理需求拆分。
- 龙虾发饰、蝴蝶结及小花按运动关系拆分。
- 头部、脖子、躯干、衣服、左右手臂及手部按遮挡和变形需求拆分。
- 被前发、手臂和衣物遮住的区域应补全，动作范围内不能出现透明破洞。
- 左右命名需说明采用角色视角还是观看者视角。

请尽可能使用 Cubism 标准参数，例如 ParamAngleX/Y/Z、ParamEyeLOpen、ParamEyeROpen、ParamEyeBallX/Y、ParamMouthOpenY、ParamMouthForm、ParamBodyAngleX 和 ParamBreath。自定义参数需附 ID、取值范围、默认值和用途说明。

## 制作与验收节点

1. 报价：分别说明立绘、拆图、绑定、表情动作、源文件和使用授权，确认工期及修改次数。
2. 草稿：确认脸、比例、发饰、服装和半身边界。
3. 上色与分层：确认颜色与小尺寸可读性，再进入绑定。
4. 绑定演示：检查转头自然、眼睛闭合正常、口腔不穿帮、头发及饰品无明显破洞。
5. 程序试装：开发方检查本地加载、透明背景、显示尺寸、参数控制、表情恢复和动作播放。
6. 最终交付：确认运行包、约定源文件、说明和授权齐全。

应将程序试装安排在最终验收前，并约定修复文件引用错误或明显绑定缺陷的范围。
