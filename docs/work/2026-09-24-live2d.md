# Shizuku 窗口陪伴接入

用户已选择窗口内角色，并授权使用现有 Shizuku 模型实现第一版。

实施范围：在聊天右侧添加独立角色区，保持输入区可用；支持本地加载、待机/眨眼/呼吸、视线跟随、点击动作和持久化收起状态。离开聊天页和收起时销毁渲染资源。WebGL 或素材加载失败时显示重试提示，聊天继续可用。

技术选择：Pixi 6.5.10 + pixi-live2d-display 0.4.0 Cubism 4 适配器；官方 Cubism Core 本地保存；通过 @pixi/unsafe-eval 的兼容补丁避免开启通用 unsafe-eval。仅放行本地素材连接及 WebAssembly 编译，不改变 Electron 隔离配置。映射 Shizuku 的旧 PARAM_* 参数；点击动作设为单次播放。

文件职责：public/live2d 保存模型、运行库及版权说明；src/live2d/renderer.ts 管理加载和释放；src/live2d/Companion.tsx 管理面板与交互；src/live2d/companion.css 管理响应式布局；App.tsx 仅接入聊天区组件。
