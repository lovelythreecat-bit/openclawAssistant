# README visual assets

- Audience: Windows users with an existing OpenClaw gateway.
- Value: a desktop workspace for conversations, models, Skills and plugins.
- Proof: existing application screenshots, with mock chat explicitly identified.
- First successful action: start Kuro, connect to the local gateway, open a conversation.
- Theme: Kuro's existing warm ivory and sakura-pink interface.

## Visual system

- Palette: ivory `#fffaf7`, foreground `#453740`, rose `#c95978`, pale pink `#fce9ef`, secondary text `#715562`.
- Type: system Segoe UI / Microsoft YaHei / PingFang SC; editable SVG text.
- Shape: 16–24 unit radii, 2–3 unit strokes, generous spacing.
- Motif: conversation bubbles and the desktop-to-local-gateway relationship.
- Composition: a compact title, followed by a full-width real screenshot; one connection diagram in the setup section.

`hero.svg` and `connection.svg` are shared by both READMEs. They have opaque backgrounds and no scripts, external fonts, images or animation. Keep commands and detailed explanations in Markdown. Review SVGs at 900px and 360px; the diagram's full meaning is repeated in adjacent text for narrow screens.

Screenshots are reused from `docs/screenshots/` and `docs/work/`. They are historical examples, not a claim that every current management page is pictured. `kuro-chat-demo.png` uses a local mock gateway. The welcome artwork is distinct from the Live2D Shizuku sample character; see `public/live2d/NOTICE.txt` for asset terms.
