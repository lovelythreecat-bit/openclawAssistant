# 库洛 · OpenClaw 桌面工作台

一个独立的 Windows 桌面客户端。库洛以樱花粉、暖白色的工作台，陪你使用这台电脑上的 OpenClaw：查看对话、发送消息、阅读流式回复，也能查看连接状态和调整配置。

应用界面名为「库洛」，Windows 可执行文件名为 `Kuro.exe`。

**本机最快启动：双击项目根目录的 `Start-Kuro.cmd`。** 若要单独携带运行文件，使用 `release/Kuro-0.1.0-Windows-x64.exe`。

第一版已通过 36 项自动测试、真实 WSL 网关只读连接、目录版交互验收和便携 EXE 启动验收。详情见 [验收记录](docs/verification-notes.md)。真实模型消息由你自行发送，本轮没有自动发起真实聊天。

## 快速开始

### 使用便携版

1. 使用本项目构建得到的 `release/Kuro-0.1.0-Windows-x64.exe`。
2. 双击启动。便携版无需安装，启动时会解压运行文件。
3. 首次启动且尚未明确配置过连接时，库洛会尝试读取 `Ubuntu-24.04` 中的 OpenClaw 配置并连接网关。手动保存或导入后，后续启动使用已保存配置；无认证网关同样会保留。
4. 看到「已连接」后，点击「开启新对话」或选择已有对话即可开始。

库洛连接现有 OpenClaw 网关，不会自动安装 OpenClaw，也不会替你启动其服务。请先保证网关正在运行，并且 Windows 能访问对应的本机端口。

首次导入失败时，打开「设置」修改 WSL 发行版名称，再点击「从 WSL 导入」；保存后在「网关」页点击「连接网关」。可以运行 `wsl --list --quiet` 查看已安装的发行版名称。

便携版指运行程序无需安装。连接设置仍保存在当前 Windows 用户的应用数据目录，不会随可执行文件移动。此项目默认构建未签名的本地应用，不包含自动安装、发布或更新流程。

### 从源码启动

需要 Windows x64、Node.js 22 或更高版本以及 npm。使用 WSL 自动导入时，对应发行版需安装 Python 3。

在项目目录运行：

```powershell
npm install
npm start
```

`npm start` 会检查 TypeScript、构建前端与 Electron 主进程，然后打开独立桌面窗口。首次安装需要下载 Electron 等依赖。浏览器单独打开 Vite 页面无法获得桌面桥接能力。

## 连接与认证

- 默认地址：`ws://127.0.0.1:18789/`。
- 仅支持本机回环地址：`localhost`、`127.0.0.1`、`[::1]`。不支持直接连接远程服务器。
- 自动导入读取 WSL 的 OpenClaw 配置，默认位于 `~/.openclaw/openclaw.json`；也会考虑 `OPENCLAW_CONFIG_PATH` 和网关服务环境中的认证信息。
- WSL 导入支持令牌、密码及无认证配置。手动填写时先选择 **Token 令牌** 或 **Password 密码**，再在遮蔽输入框中填写对应凭据；密码首尾空格会原样保留。保存成功后输入框清空，不显示已有秘密。
- 保存设置或重新导入配置会断开当前网关，并清空当前会话视图及未发送草稿。重新连接后从对应网关加载记录，避免不同网关的同名会话混在一起。
- 在地址和发行版不变时，凭据留空可保留已有认证。更换地址或发行版会清除旧认证，请重新导入或填写对应令牌/密码。

连接配置和设备身份保存在 Electron `userData` 目录的 `connection.sealed` 中，由 Electron `safeStorage` 使用 Windows 系统能力加密。请使用保存配置时的 Windows 账户启动；界面不显示已保存的凭据。应用不持久化本地聊天消息缓存。

## 使用方式

- 聊天窗口右侧显示 Shizuku 动态角色，支持待机动作、眨眼、呼吸和视线跟随。点击角色或「打个招呼」可播放一次互动动作。
- 点击角色区右上角箭头可收起；右侧「陪伴」按钮可展开，收起状态会记住。收起或离开聊天页会释放角色渲染资源。
- 模型与运行库均随程序本地打包，角色显示无需联网。图形功能不可用时可继续聊天，并重试加载角色。系统开启「减少动态效果」时角色静止展示。
- 当前使用 Live2D 官方 Shizuku 示例角色；聊天中的思考和回复状态以角色下方文字提示，尚未接入语音或专用情绪表情。素材来源与授权链接见 `public/live2d/NOTICE.txt`。

- 欢迎页的建议卡只填入草稿，确认后自行发送。
- `Enter` 发送，`Shift + Enter` 换行；输入法组合输入期间回车不会发送。
- 支持按名称搜索会话、刷新列表和聊天记录。会话列表最多读取 100 条，每个会话显示最近 200 条历史消息。
- 每个会话有独立草稿和运行状态，可以在回复过程中切换会话。
- 回复支持 Markdown 文本、列表、表格和代码块；HTTP/HTTPS 链接通过系统浏览器打开。历史图片以文字占位，不支持上传附件。
- 收到网关工具活动事件时显示工具名称和阶段。没有收到完成确认时，界面不会将停止请求当作已完成。
- 连接断开或发送结果不确定时，请重新连接并刷新记录，确认消息是否已经送达，再决定是否重试。

## 构建 Windows 产物

```powershell
# 构建主进程与前端
npm run build

# 构建可直接运行的目录
npm run package:dir

# 构建免安装便携 EXE
npm run package
```

产物目录：

```text
release/
  win-unpacked/
    Kuro.exe
    resources/
    ...
  Kuro-0.1.0-Windows-x64.exe
```

`package:dir` 生成目录版；`package` 生成便携 EXE，并保留打包过程中产生的 `win-unpacked`。目录版分发时需保留整个目录，不能只复制其中的 `Kuro.exe`。版本号来自 `package.json`。

打包器会按需下载 Windows 打包工具。配置包含已构建前端、Electron 主进程、预加载脚本、角色图片和生产依赖；不会把 WSL 配置或用户凭据打入产物。默认关闭 Windows 代码签名，保留图标与程序信息，且禁止发布。

## 常见情况

| 情况 | 处理方式 |
| --- | --- |
| 找不到 WSL 配置 | 检查发行版名称、Python 3 和 OpenClaw 配置位置，再从设置重新导入。 |
| 网关连接失败 | 确认网关已启动、端口正确，且 Windows 可以访问本机回环地址。 |
| 自动导入提示扩展 JSON 不受支持 | 当前导入器使用标准 JSON 解析；可在设置中手动填写地址并选择 Token 或 Password 认证。 |
| 网关要求设备配对 | 按网关提示使用 OpenClaw 现有的设备审批流程，再重新连接。 |
| 无法读取加密配置 | 使用原来的 Windows 账户和正常桌面用户会话启动。 |
| 回复中途断线 | 重新连接并刷新记录，确认已发送和已生成的内容后再继续。 |
